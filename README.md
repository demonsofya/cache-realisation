## Краткое описание кешей

### LFU-cache
Счетчик частоты хранится в `list` как пары `ключ : число обращений`, сам cache — в `unordered_map` как `ключ : значение`.  
Список упорядочивается по частоте обращений: в начале находятся наименее часто используемые элементы. Новый элемент добавляется в начало с частотой `1`. При переполнении удаляется элемент из начала списка.

### LRU-cache
В `list` хранятся элементы в порядке последних обращений, в `unordered_map` — пары `ключ : итератор list`.  
При обращении элемент переносится в начало списка. При добавлении нового элемента удаляется последний элемент, то есть тот, к которому дольше всего не обращались, а новый вставляется в начало.

### 2Q-cache
Кеш состоит из трех частей: `A1in`, `A1out` и `Am`.  
`A1in` хранит недавно добавленные элементы, `A1out` — только ключи элементов, вытесненных из `A1in`, а `Am` реализован как LRU и хранит элементы, к которым обращались повторно. Новый элемент попадает в `A1in`. При вытеснении из `A1in` его ключ переносится в `A1out`. Если элемент снова найден в `A1out`, он загружается и помещается в `Am`.
