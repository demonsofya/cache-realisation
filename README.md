# cache-realisation
Реализация разных кешей на c++

lfu-cache: счетчик через list, сам cache - unordered map. При добавлении нового он добавляется в начале листа, т.е. будет удален первым если к нему больше не будет обращений

lru-cache: в list хранится отсортированные по обращениям элементы, в unordered map - пара ключ : итератор листа. При добавлении нового элемента удаляется последний, новый вставляется в начало
